微觀幾何
撞擊角 θi 計算公式：

$$\sin(\theta_i) = \frac{W_i}{L_i} \implies \theta_i = \arcsin\left(\frac{W_i}{L_i}\right)$$

量度規範重點 (Measurement Protocol)： 必須僅測量顆粒主橢圓體之短軸 Wi 與長軸 Li。若包含尾端（Tail），會使長軸 Li 虛高，導致撞擊角 θi 嚴重偏小！

典型作偽數據

題目情境條件：

鑑測人員在牆面上測得顏料微粒 P1 坐標為 (12.0 cm, 15.0 cm)。顯微鏡下量得短軸 W1 = 2.1 mm，長軸 L1 = 4.2 mm，前進指向角 α1 = 45°。已知 2D 匯聚點解得為 (X0, Y0) = (0.0 cm, 0.0 cm)。求撞擊角 θ1、距離 d1 與離牆高度 Z1。

步驟一：求解撞擊角 θ1 Step 1

帶入短長軸比例：

$$\sin(\theta_1) = \frac{W_1}{L_1} = \frac{2.1\text{ mm}}{4.2\text{ mm}} = 0.5$$

$$\theta_1 = \arcsin(0.5) = 30.0^\circ$$

步驟二：求離牆 2D 距離 d1 Step 2

計算微粒到匯聚點距離：

$$d_1 = \sqrt{(12.0 - 0)^2 + (15.0 - 0)^2}$$

$$d_1 = \sqrt{144 + 225} = \sqrt{369} \approx 19.21\text{ cm}$$

步驟三：重構 3D 源頭高度 Z1 Step 3

正切函數求解高度：

$$Z_1 = d_1 \cdot \tan(\theta_1) = 19.21 \times \tan(30^\circ)$$

$$Z_1 = 19.21 \times 0.57735 \approx 11.09\text{ cm}$$
